# RETRIEVE @ MICRO 2026

Browser presentation for *Exploring Predicate-Agnostic Search on cuVS CAGRA*.

- [Audience slides](https://namanhboi.github.io/retrieve-2026-talk/)
- [Presenter view](https://namanhboi.github.io/retrieve-2026-talk/?presenter=1)

Arrow keys, Space, or Page Down advance animations. Press **P** for presenter notes, **F** for fullscreen, and **B** for slides and backups.

Open audience and presenter views in the same browser to synchronize them. Prepared notes and Q&A are embedded. Personal edits save in that browser; use **Export notes** to keep a copy. Saved edits from a local-file copy do not automatically transfer to this address.

The site is self-contained in `index.html`. Replace that file with a newer exported browser deck to update the presentation. GitHub Pages publishes the `main` branch root.
